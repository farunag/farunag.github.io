# farunag.github.io

Personal academic website of Godwin Abuh Faruna, served by GitHub Pages at https://farunag.github.io

- `index.html` — the whole site (edit News by copying a `<li>` line to the top of the News list)
- `assets/Godwin_Faruna_CV.pdf` — CV linked from the site
- `cv/Godwin_Faruna_CV.tex` — LaTeX source for the CV (build with `pdflatex`, then copy the PDF into `assets/`)
